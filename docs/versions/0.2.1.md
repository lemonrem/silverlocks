# Silverlocks 0.2.1

Date: 2026-09-06

## Outcome

Planning now carries existing user authorization forward. Higher-risk work still receives
proportional planning and verification, but planning alone no longer triggers another approval.
Missing material choices or authority still require clarification. Follow-ups preserve the active
task unless the user changes it.

The updater now rejects missing, empty, symlinked or directory-shaped required files, including
the three workflow references. The installed revision remains unchanged on these rejections.

## Scope and verification

Changed SKILL.md, the planning and update references, update.py, its tests, bilingual README,
VERSION and CHANGELOG. No business repository or runtime changes are required.

The Python unittest suite passed all 20 tests, including four damaged-update scenarios.
Git whitespace validation passed. The suite covers clean fast-forward, local-change preservation,
divergence rejection, caching and continuity-state handling.

## Recovery

Retain a local backup before replacing an older installed workflow skill. Restore that installation
if needed; preserve workspace continuity and archives. Do not reset a dirty checkout to downgrade.
Publishing uses the source commit containing this record; local installation should match that
commit and keep its Git metadata for future updates.
